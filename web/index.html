Local Agent Devices

Secure managed-device detection and operations

Local Agent scans report only supported tools and basic device metadata. Supported search locations are PATH, standard installation directories, and supported package records—not unrelated personal files. Local install/update requires admin authentication here and a second approval in the agent console. Browser confirmation alone never authorizes installation.
Enter the administrator key to view paired devices.

Pair and run the Local Agent

1. On the FastAPI server, set separate random values of at least 32 characters for ESIM_PAIRING_SECRET and ESIM_AGENT_ADMIN_KEY, then serve the API over HTTPS. Keep both values out of source control.

2. On the Windows or Linux computer, check out this repository and install the agent dependency: python -m pip install "platformdirs>=4,<5".

3. Pair that computer with python -m local_agent --backend https://<your-api-host> pair. The pairing secret is entered through a hidden prompt and the device token is stored in the user config store.

4. Start initial scan, heartbeats, job polling and scheduled scans with python -m local_agent --backend https://<your-api-host> run. Keep this process running, or configure your operating system to start it at user login. This repository does not install a native Windows service or Linux service unit. Manual scan: python -m local_agent --backend https://<your-api-host> scan.

Real-device validation: Local Agent detection and operations have not been verified on a real Windows or Linux laptop in this development environment. Linux installation uses supported apt/apt-get mappings; Windows uses winget. NgVeri has no verified package mapping and uninstall is disabled. Latest versions remain unknown without an authoritative version feed.
